# PERFORMANCE_BUDGETS.md — Бюджеты производительности «Кока-Коля»

Целевая платформа: PC (Windows)  
Базовый профиль тестирования: Recommended (1080p @ 60 FPS, Frame Time <= 16.67 ms)

---

## 1. Бюджеты кадров и железа

| Профиль | Разрешение / Пресет | Целевой FPS | Предел Frame Time | Предел RAM | Предел VRAM |
|---|---|---|---|---|---|
| **Minimum** | 720p / Low | 30 FPS | 33.33 ms | <= 8.0 GB | <= 4.0 GB |
| **Recommended** | 1080p / Medium-High | 60 FPS | 16.67 ms | <= 10.0 GB | <= 6.0 GB |
| **High / Ultra** | 1440p-4K / High | 60-120 FPS | 8.33 - 16.67 ms | <= 12.0 GB | <= 8.0 GB |

---

## 2. Лимиты физики и рендеринга (на кадр в сцене)

- **Активные RigidBody3D**: <= 64 одновременно активных (остальные в Sleep).
- **Draw Calls**: <= 1500 per frame на Recommended.
- **Полигоны (Triangles)**: <= 1.5 - 2.5 млн видимых полигонов.
- **Источники света с тенями (Shadow casters)**: 1 Directional (Солнце/Луна) + до 4 локальных источников.
- **Активные AI агенты**: до 16 полнофункциональных CharacterBody3D рядом с игроком; дальняя массовка — через Data-Simulation.
- **Время загрузки локации (SSD)**: <= 15-20 секунд со старта игры; <= 8-12 секунд при быстром перемещении.
